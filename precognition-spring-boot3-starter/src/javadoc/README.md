# Spring Precognition boot3 starter

This artifact aggregates dependencies and contains no Java classes.
The Java API is provided by precognition-core and the MVC implementation by
precognition-spring-webmvc. See the corresponding source and Javadoc artifacts.

Installation and usage: https://github.com/hozdemir/spring-precognition
